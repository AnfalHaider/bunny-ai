Code

    

      

        

          
Default permission mode

          
How careful a new chat starts out. You can change it per chat under the message box. In Auto, commands run without asking, and a command can read anything your Windows account can, Bunny's saved keys included.

        

        

          
        

      

      

        
Permission rules

        
Rules are checked before the permission mode. Deny always wins, then Ask, then Allow. Plan mode still refuses edits whatever the rules say. A command pattern like npm test* matches what Bunny is about to run; a path pattern like secrets/** matches the files Bunny's own tools read or edit (not what a command does). Simple wildcards only: * and **.

        
Only from Bunny's window. In the desktop app, the rules, the permission mode, connectors, schedules, hooks, skills, sign-ins, providers, automatic updates, "use another model when busy" and the other settings that decide what Bunny may do change only from this window. Anything else on this computer that tries gets "Change this in Bunny's window.", which means the request was refused and nothing was changed.

        
A guard rail, not a sandbox. Command rules read the command Bunny is about to run; they do not cover custom tools, MCP or local connectors, computer-use typing, the browser tools or schedules, and a wrapper such as cmd /c or powershell -Command can hide what it runs (Bunny asks about those when you have a Deny or Ask rule).

Desktop app

    

      

        

          
Quick ask

          
Press Ctrl+Alt+Space anywhere to ask Bunny in a small bar. It answers right there, as plain text: it never uses tools or asks for permissions in the bar. Press Open in Bunny to carry the chat over to the main window; the chat is kept in your list, tagged Quick ask. Needs Bunny to keep running in the tray.

Allow other devices to open Bunny

          
Lets a phone or another computer on your own network open Bunny, after a passcode. It is off until you turn it on, then it stays on, also after Bunny restarts, until you turn it off. Devices sign in again after a restart. Local network only: never forward a router port to it.

          

          

        

        

          
        

      

      

        
Before you turn this on. This uses plain HTTP, not an encrypted connection: anyone on the same network who can see its traffic could take over a signed-in device and run programs on this computer. Use it only on your own home network, never on public or shared Wi-Fi. Once on, it stays on until you turn it off, also after Bunny restarts, but only on the network you turned it on with; devices sign in again each time. Anyone on your network who has the passcode can chat with Bunny and read your chats from their device. A device you have just signed in gets Chats: ordinary chats, with their tools, and it can answer a chat's own permission questions there. It cannot change what Bunny may do: the default mode, rules, connectors, installs, skills, schedules, providers, accounts and updates stay in this window. You can give a device Everything (the same as this window) for that device only, from this window, after a warning; it ends after 30 minutes without use. The first time, Windows asks about the firewall: choose Private networks only, never Public.
