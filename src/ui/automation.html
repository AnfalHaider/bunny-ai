Automation

Memory, tools, schedules, hooks and skills. Everything here is stored on this machine.

Memory

Things the model is told about you in every chat. Switch one off without losing it.

MCP servers

Tools that live outside this app. The tools are offered to the model when it is switched on.

Schedules

A prompt that runs on its own. Each run is kept as a chat.

Hooks

A command that runs when something happens. Hooks are off until you switch them on.

Skills

A short instruction that can be switched on for your chats.
