## Quick ask just works

- Ask the Quick ask bar to find a file and it searches this PC. Ask it about the weather and it searches the web. For most questions it no longer sends you to the app.
- **Search this PC is on by default, for finding files only.** File names and folders it finds go to the model. Reading a file's text is still your choice. The first search says so once and names where to turn it off: **Settings › Capabilities**. If you turned Search this PC off before, it stays off. A phone signed in for Chats never searches this PC.
- If search is off, the bar says so and gives you a button to the switch.
- The bar names the tools it really has.

## Auto that checks itself

- **Smart start:** while Bunny's check is on, new chats start in Auto inside folders you trust that are git projects. They start in Ask everywhere else: in other folders, on a phone or other device, and when the check can't answer.
- **A second model checks risky steps in Auto:** commands, connectors, computer and browser clicks, downloads and installs. You can turn the check off in **Settings › Permissions**.
- **In Auto, Bunny's check looks at commands, connectors and installs. It does not look at edits to files inside your folder. If a chat edits a script and later runs it, the check sees only the command. Review the Changes tab before you run project scripts.**
- **The trust card:** the first time you work in a folder, one card asks two things: follow its instruction files, and run in Auto there. You read the instruction files before you can follow them.
- **Command confinement:** commands can write only inside the project folder. Choose **Off**, **On in Auto** (the default) or **Always** in **Settings › Permissions**. A chat can also remove its own label. Windows only.
- **Allow for this chat:** for narrow kinds of step: one command, edits in one folder, one connector tool, or changes on the site open in the browser panel.
- **Safe read-only commands**, such as `git status`, run without a card in Ask mode.

## Rules you write

- Website rules, rules by connector tool name, and rules for helper agents and chats messaging each other. Deny always wins, and sending always asks.

## One set of project instructions, every engine

- Bunny, Claude Code and Codex read the same instructions: the folder's AGENTS.md, or CLAUDE.md when there is no AGENTS.md. Cursor's `.cursorrules`, and `.cursor/rules` files marked alwaysApply, are added after it.
- Each engine gets exactly the text you were shown. If a file changes on disk, Bunny tells you and asks you to read it again.

## Switch engines mid-chat

- Switch a chat to Claude Code, Codex or Bunny's engine from the engine chip. The new engine gets the same folder, the instructions, a summary of the conversation and the list of files the chat changed.

## A new chat knows the project

- New chats in a project start with the project's memory and recent context, so you don't have to explain the project again.

## Rewind

- Go back several replies in a chat, with the files Bunny changed restored.

## Install from anywhere

- Bunny can find and install connectors, skills and plugins from any https address, git hosts, npm and PyPI, not just its catalogue.
- **One install card** shows exactly what will be installed and where it came from, pinned to that version. You choose **Install and switch on**, **Install, keep off** or **Don't install**. A plugin, skill or package found on the open web lists **Install, keep off** first.

- Stripe is not on the recommended tools list for now.

## Known limits

- **What command confinement doesn't cover:**
  - reading files, and the network;
  - custom tools, local and other connectors, and browser and computer use;
  - engines: Codex has its own sandbox, and Claude Code on Windows has none.
- **Your files are protected by other checks:** Bunny's file tools stay inside the folder by their own checks, not by confinement.
- **The confinement label:** while it is on, other low-rights programs on this PC can also write in the folder. Remove the label when you no longer need it.
- **Rewind:** it doesn't undo changes made by commands; the preview says when a reply ran one.
- **Not yet blocked:** hard links, and Auto-check reviews of edits to scripts and project files. v0.1.16 adds both.
