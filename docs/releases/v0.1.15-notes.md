## Quick ask just works

- Ask the Quick ask bar to find a file and it searches this PC. Ask it about the weather and it searches the web. It no longer sends you to the app for things it can do itself.
- **Search this PC is on by default, for finding files only.** File names and folders it finds go to the model. Reading a file's text is still your choice. The first search says so once and names where to turn it off: **Settings › Capabilities**. If you turned Search this PC off before, it stays off. It is never available to a phone signed in for Chats.
- If search is off, the bar says so and gives you the switch.
- The bar names the tools it really has.

## Auto that checks itself

- **Smart start:** new chats start in Auto inside folders you trust that are git projects, and in Ask everywhere else.
- **A second model checks risky steps in Auto:** commands, connectors and installs. Anything unclear is blocked, and you see every verdict. Turn it off in Settings if you want.
- **In Auto, Bunny's check looks at commands, connectors and installs. It does not look at edits to files inside your folder. If a chat edits a script and later runs it, the check sees only the command. Review the Changes tab before you run project scripts.**
- **The trust card:** the first time you work in a folder, one card asks two things: follow its instruction files, and run in Auto there. You read the instruction files before you can follow them.
- **Command confinement:** in Auto, commands can write only inside the project folder. They can still read and reach the network, and the help says so. Turn it off per folder.
- **Allow for this chat:** for narrow kinds of step, such as one command word, edits in one folder, one connector tool or one website.
- **Safe read-only commands**, such as `git status`, run without a card.

## Rules you write

- Website rules, rules by connector tool name, and rules for helper agents and chats messaging each other. Deny always wins, and sending always asks.

## One set of project instructions, every engine

- Bunny, Claude Code and Codex read the same instructions: the folder's AGENTS.md, or CLAUDE.md when there is no AGENTS.md. Cursor's `.cursorrules`, and `.cursor/rules` files marked alwaysApply, are added after it.
- Each engine gets exactly the text you were shown. If a file changes on disk, Bunny tells you and asks you to read it again.

## Switch engines mid-chat

- Switch a chat to Claude Code, Codex or Bunny's engine from the engine chip. The new engine gets the same folder, the instructions, a summary of the conversation and the list of files the chat changed.

## A new chat knows the project

- New chats in a project start with the project's memory and recent context, so you don't have to explain the project again.

## Rewind

- Go back to any earlier point in a chat, with the files restored, not just the last reply.

## Install from anywhere

- Bunny can find and install connectors, skills and plugins from any https address, git hosts, npm and PyPI, not just its catalogue.
- **One install card** shows exactly what will be installed and where it came from, pinned to that version. You choose **Install and switch on**, **Install and keep off** or **Don't install**. Anything found on the open web lists **Install and keep off** first.
- Connectors you added before this version are kept as they were and marked for review.

## Office files

- Bunny can create Word, Excel and PowerPoint files.

## Claude Code sign-in

- The Claude Code sign-in page now opens in your normal browser. The engine's dialog says only what happened.

## Settings, rebuilt

- Clearer sections, including a new **Permissions** section for your rules.
- **English only for now:** the Language picker is gone.
- Google sign-in shows why it is greyed out and how to connect it.

## Safer file writes

- Bunny's file tools no longer write through links (symbolic links or junctions), so a file in a cloned project can't send a write outside the folder or into Bunny's data.

## Other changes

- Web searches go to Brave when you have set a Brave key.
- Stripe is not on the recommended tools list for now.

## Known limits

- Command confinement doesn't stop reading files or using the network.
- Hard links are not yet blocked by the link check; v0.1.16 adds that.
- In Auto, edits to scripts and project files aren't checked by the second model; v0.1.16 adds that.

## Updating

Copies update on their own (**Restart to update**, or check for updates in **Settings → About**).
