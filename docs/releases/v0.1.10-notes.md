## Use Bunny in your browser

- **Settings → Desktop app → Use Bunny in a browser → Open in your browser** (also in the tray menu) opens me in your normal browser at an address on this computer only. **Keep the same address after restart** keeps a bookmark working.
- In a browser tab, the settings that decide what I may do (permission mode and rules, connectors, installs, updates) are greyed out and say **Change this in Bunny's window.** So are the Allow buttons on my cards.
- **Allow other devices to open Bunny** (off by default, and off again after every restart) lets your phone or laptop on the same home network sign in with a passcode you choose. Only a scrambled form of the passcode is stored. After 5 wrong tries the device waits. Settings lists the signed-in devices, with **Sign out** for each, and my window shows **Open to other devices · N signed in · Turn off** while it's on.
- A signed-in device gets full chats: it can use tools, answer its own chat's permission and question cards, and pick its chat's mode and model. Computer control, installs, connectors, schedules and memory stay with my window, and so do all settings. If a device puts a chat on **Auto**, my window shows it, and the chat goes back to Ask when the device signs out or goes idle. Devices are signed out after 2 hours idle.
- The connection between devices is plain HTTP: use it only on your own home network, never on public or shared Wi-Fi, and choose **Private networks only** when Windows asks about the firewall.

## Quick ask answers in place

- Ask from the quick-ask bar and the answer appears right there, with **Stop**, **Copy**, a follow-up box and **Open in Bunny** to carry on in my window. The chat is kept, tagged **Quick ask**.
- Answers in the bar are text only. If a question needs a tool, the bar says **This needs Bunny's window**, and nothing is ever approved from the bar.

## Model picker

- The model picker sits beside **Send** and opens upward as a floating panel (a sheet from the bottom on a phone), with search, filters, favourites, details and the thinking level.

## Settings

- Every change made in Settings now saves in the desktop app. Before this, changes like uninstalling a plugin, adding a connector or editing permission rules could fail with "Change this in Bunny's window."
- The same plugin, typed as a different address, is no longer installed twice.

## Code chats

- A code chat can work in **its own copy** of your project (a git worktree), shown on the **Working folder** card; **Finish** keeps, merges or discards the work, and deleting the chat keeps its branch. Leftover copies are listed in Settings.
- I won't make a copy of a project whose own git settings would run its own programs when files are checked out, or that pulls in other git settings files.
- A new **browser_compare** tool compares two pages side by side at several widths.

## Safer by default

- An artifact opened in its own window is a plain page with no access to my controls, and printing an artifact happens in a sealed-off frame.
- I run git, PowerShell and other system programs only from their real locations, never a same-named program inside a project. My own git calls run none of a project's hooks, filters or signing programs.
- Your GitHub sign-in no longer appears on git's command line.
- My tools can't read or change my own data folder, where your keys and sign-ins are kept, and saved secrets are tied to this installation.
- I ask before moving a request to a new chat, and show a memory import before saving it.
- Updates download into my own folder and are checked again just before they install.

## Also

- The thinking choice is kept per provider and model, a waiting card nudges you again after a while, and an old failure note clears when you send a new message.
- The full release notes are shown in **Settings → About**.
- In **Auto**, commands run without asking, and a command can read anything your Windows account can, my saved keys included; the help text now says so.

## Updating

Copies update on their own (**Restart to update**, or check for updates in **Settings**).
