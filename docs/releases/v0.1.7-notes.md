## I keep going until the job is done

- No more typing "continue". Big jobs keep going past the old step limit (up to 500 steps or 2 hours, set in **Settings → Code**), with "Still working · step N" so you can see where I am.
- I ask with a card when I genuinely need you, instead of stopping on "Please confirm…". If I stop without a plan, I'm nudged to make a task list and carry on.
- If one model fails mid-job, the next one picks up with everything I've already read, not a 300-character summary.
- A token budget (5 million per job by default) and a loop check: I ask before going further, and I notice when I'm repeating myself.
- Tool calls a model writes as text are run, never shown to you as raw markup, and a call cut off mid-way is never run half-finished.

## One working line

- The thinking row and the hopping bunny are now one line at the bottom of my reply: "Snuggling the code… thinking · 12s". Open it to read my thinking; it settles into "Thought for 12s" when I move on. When a model is slow, I say which one I'm waiting for.

## Better tools for code

- Search with regular expressions, file patterns and context lines; find files by pattern; replace every match or make several edits in one go, with a single Undo.
- Searches that would take too long stop after 5 seconds with a clear message.

## Permission rules

- In **Settings → Code**, say "always allow `npm test*`", "always ask before `git push*`" or "never touch `secrets/**`", for every folder or one. Deny always wins; **Try a command** shows what I'd do. A blocked step shows an amber **Blocked** label.

## Safer by default

- In the desktop app, your permission mode, rules, connectors, schedules, sign-ins, providers, update settings and similar switches change only from my own window. Another program on your PC can't quietly change what I may do.
- Programs I start now stop when I close.
- Reconnecting after my server restarts is fixed: a request that raced the reconnect is now sent again instead of failing.
