## Install Bunny as a web app

- When you open Bunny in your browser on this computer (**Settings → Desktop app → Use Bunny in a browser → Open in your browser**), you can install it as an app with its own icon and window: **Install as an app** in Settings, or your browser's own install button.
- On another device over your home network, browsers allow only a home-screen shortcut, because the connection there is plain HTTP. On an iPhone, **Share → Add to Home Screen** opens Bunny full screen.
- The installed app fits around a phone's notch and home bar, and its title bar takes Bunny's own colours.
- If Bunny isn't running, the app shows **Bunny is not running** and comes back by itself when Bunny starts.
- When a new version is ready, a small **Update ready · Reload** line appears under the top bar. Nothing switches while you're working.

## Safer by default

- The web app keeps only Bunny's own static files (styles, scripts, icons). It never stores a page, your chats, or anything from Bunny's server.
- The older offline helper from 0.1.9 and 0.1.10 kept a copy of the main page. It is replaced, and cleared in Bunny's own window in the background when Bunny starts (it tries again on the next start if that takes too long), and in each browser the next time you open Bunny at its address.

## Updating

Copies update on their own (**Restart to update**, or check for updates in **Settings → About**).
