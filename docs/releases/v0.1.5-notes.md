## A chat that shows its work like Claude's

- Tool steps are grouped into one line with a plain summary; open a group to see each step.
- A command that fails shows a red **Failed** label with the exact command and its output.
- Short narration between steps, and a clear report when Bunny stops.
- A little purple bunny hops while Bunny works, with words that match the step.

## When a model fails, Bunny keeps going

- A model that does not answer is dropped after about 30 seconds (it was 2 minutes), and the next suitable model answers. You see one quiet line ("Answered by X because Y did not answer in time"), never a stack of red errors.
- If your computer is really offline, Bunny says so calmly, keeps your message waiting, and sends it once when the network is back. A model running on your own computer answers in the meantime.

## Changes, Files and Session panes that work

- **Changes**: every file Bunny changed, with real line counts, diffs and "Undo to here", in git and plain folders.
- **Files**: browse the folder and read any file; Bunny's edits are marked.
- **Session**: folder, branch, model (and why Auto chose it), permissions, effort, context, tokens, connectors and running programs.

## Safer by default

- Bunny's local server now answers only Bunny's own windows: a web page open in your browser can no longer drive it.
- Folders are chosen with the desktop folder picker only.
- Plan mode is really read-only: Bunny can look, ask and make artifacts, but cannot change files or run anything.
- Permission modes do exactly what they say: in Auto, actions you allowed run without asking; Manual and Accept edits ask; sending email always asks.

## Fixes

- Background commands with `&`, a browser that opened before a server was ready, a mode choice that reset itself, a stopped reply that vanished, Rename in the desktop app, a stale page after a restart, phone layouts for Settings and the top bar, and more.
