## A better model picker

- One row per model, with every provider that has it shown as a tag. **Free** and **Free daily** tags tell you what costs nothing; a **Free only** switch shows both.
- **Filters** by provider, by what a model can do (Code, Pictures, Images, Video, Speech) and by free; the list says "N of M models". **Sort** by recommended, name or context size, with the context size on the right.
- **Favourites** and **Recent** at the top. **Details** on each model: put its providers in your own order with the arrows (kept on this computer), and star it as a favourite.
- When the provider of the model you picked fails or runs out, I switch to the same model on the next provider and say so in one amber line under the reply. I never switch to a different model without telling you.

## Questions I ask you can be answered

- A "Bunny asked" card can be answered by typing in the message box ("stop here", "yes, but skip the tests"), not only by clicking. A card you skipped says so, and a card that could no longer be answered (the window was closed while I waited) says that instead of showing dead buttons.

## Quick ask

- A prompt bar on a shortcut (**Ctrl+Alt+Space**) that opens a new chat with what you typed, and a screenshot only when you click to add one. Turn it on in **Settings**.

## Connectors, plugins and sign-in

- Connectors that need you to sign in can now do it (OAuth), from **Customize** or from the chat; the status shows as a plain word, and a refused key says so.
- A sign-in is sent only to the place it was given for. A connector on the internet cannot point at your own computer or network.
- Plugins can be **uninstalled**, and uninstalling signs their connectors out.
- A local connector can take up to five minutes to start the first time, with progress shown, and stopping it stops everything it started.

## Models and replies

- A setting for how long I wait before trying another model (**Settings**: 15 to 120 seconds, or your own number from 10 to 600).
- A model that is only busy rests for two minutes; only a spent usage allowance rests the whole provider.
- Tool results reach the model up to 50,000 characters, up to 50,000 from a command; a screenshot from the browser reaches a model that can see, up to 12 MB.
- In **Plan** mode I now say I cannot run commands, and I can ask to leave Plan mode with a card that only you can answer. I no longer ask you to run commands for me.

## Code

- New tools: download a file into the folder (50 MB, public addresses only, undoable), check which versions of node, npm, git and python the project needs, and read a folder or a file address inside the folder.
- `run_command` takes a time limit (1 to 600 seconds) with a countdown, and its output is kept whole. When a command fails because it was written for another shell, I get a hint for PowerShell; a server or watcher is started with `start_process` instead.
- In **Auto**, a new tool, a schedule that may change things, and a local connector still ask first. A schedule's card shows what it will do.
- A confirm card is never cut: anything over 2,000 characters is refused instead of shown in part.

## Also

- Spell check languages and a right-click menu with suggestions, add to dictionary and copy link.
- Smaller fixes to the command palette, one-line transcripts, new terminal and Settings.
