What shipped in 0.1.5

The chat, like Claude's

  • Tool steps grouped into one line with a summary; open a group for each step.
  • A failing command shows a red Failed label with the command and output (your "exit code 1 … done" screenshot).
  • Narration between steps; the Stopped report appears at once.
  • The purple hopping bunny, from the accent colour.

Model switching and offline

  • A stuck model is dropped after about 30 s (was 120 s). Measured: picked model 33 s, Auto 64 s, all stalled 93 s (was 363 s).
  • One quiet line says who answered and why; no stacked red errors.
  • Offline only when the browser and a network check agree: your message waits and sends once on reconnect; a local model answers meanwhile.

Changes, Files, Session

  • Changes: real line counts, diffs and Undo to here, in git and plain folders.
  • Files: read-only tree and viewer, Bunny's edits marked.
  • Session: folder, branch, model and Auto's reason, mode, effort, context, tokens, connectors, running programs.
  • The dead Plan pane is gone (Tasks shows the plan).

Safety

  • The local server answers only Bunny's own windows (Host, Origin, per-launch token); the Google sign-in return is the one exception, with a one-time code.
  • Folders are chosen with the desktop picker only; drive roots and Bunny's data folder are refused.
  • Plan mode is read-only on the server, and can still ask and make artifacts.
  • Your rule: in Auto, allowed actions run without asking; Manual and Accept edits ask; email always asks.

Also fixed: trailing & in commands, the browser opening before a server was up, a mode choice that reset, a stopped reply that vanished, Rename in the desktop app, a stale page after a restart, phone Settings and top-bar targets, the false "restarted" banner, a cached-page service-worker bug.
