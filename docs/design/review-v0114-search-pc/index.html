Search this PC

v0.1.14 drawing for the owner's wish: ask Bunny from the Quick ask bar or the chat to find something on this computer and tell you about it. Invented files only. Nothing here is built.

What this is, in one paragraph

Bunny gets one new, read-only ability: ask Windows' own search index (the one behind the Start menu and File Explorer) for files by name, folder, date and a snippet of text. It is off until you turn it on in Settings, it never changes, moves or deletes a file, and the folders you exclude are never searched. A setting decides what happens after a search: read the best files, then answer with links to them (the owner's wish), or show what was found and read a file only when you ask.

Risk for Security: HIGH. This reads files outside the project folders and, in "read then answer", sends their contents to the model you use (a cloud model, unless you use a local one). It needs Security's requirements and the owner's go before anything is built. The list for Security is at the end of this page; the owner's questions are right after it.

For Security

WhatWhy it mattersProposed rule
Reads outside the project foldersThe first Bunny feature that reads the person's whole computer, not just a chosen folder.Off by default; the switch is the permission; read-only; only what Windows Search has indexed (Bunny builds no index of its own).
File text goes to the modelIn "read then answer" the contents leave the PC for a cloud model unless the model is local.The dialog names the provider and says what is sent; the "Read 2 files" line shows which files; caps of 3 files and about 20 000 characters each; "Show what was found" sends no text.
Excluded foldersKeys, browser profiles, Bunny's own data and password stores must never be read.Fixed exclusions the person cannot remove; the person's own list; checked after resolving links and junctions, on search results and again on the read.
File text is untrustedA file can contain text that tries to give the model instructions.The text is passed as data in a marked block; the bar stays text-only; the only tool in play is read-only search, with no write or run tool beside it.
Open could run a programA result list that opens anything could launch an installer or script.Open only for a fixed list of document, text, picture and Office kinds; everything else "Show in folder".
Remote devicesA phone must not be able to search the PC through Bunny.Window and Everything-level devices only; Chats-level devices are refused; both logged.
RecordThe person should be able to see what Bunny looked at.Activity logs each search and each read by name, not by content, and not the typed question beyond a short label.
Query handlingThe question becomes a Windows Search query.Built from escaped parts, never by pasting the question into a query; a result cap (50) and a time limit (10 s).

Questions for the owner

  • Starting choice. When you turn Search on, should "Read the files, then answer" be pre-chosen (what you asked for), or "Show what was found" (safer)? The page draws the first.
  • Quick ask. Should the bar search by itself when you ask about a file (drawn), or only when you pick "Search this PC" from the + menu?
  • Files Windows has not indexed are not found; Bunny will not scan the disk itself. Is that acceptable for the first version?
  • The go. This page asks for the owner's go to build it, after Security's requirements.
