A new chat in a project starts informed

v0.1.15 · PROJECT-CONTEXT (MEDIUM) · from Tech Lead's spec, efbb559d · invented profile only (project "Carrot shop" of "Sam")

For approval

In short

The owner: "in the same project when i start a new chat it has no context, and knows nothing." Today a project is only a name and an instruction box: no folder, no memory, and a new chat is not told its earlier chats exist. Proposed: a new chat in a project gets five labelled parts, and the person can see, edit and switch off every one.

  • P1 your every-chat instructions · P2 this project's instructions · P3 project memory · P4 the folder's instruction files · P5 recent work in this project.
  • The project can have an optional folder: a new chat there starts in Code mode in that folder.
  • Project memory is kept only on your yes. Bunny may suggest items under a reply; nothing is stored until you press Keep, and there is no auto-accept.
  • Recent work is built by Bunny from the project's last five chats, as quoted data, never instructions; a chat that used files from this PC is left out.
  • What this chat was given shows all five parts, with sizes and the exact text. Switches exist per project, per chat and globally, and all are window-only.

Per chat (in "What this chat was given")

Use project context in this chatOff sends only this project's own instructions (P2).

Globally (Settings → Memory and instructions)

Use memoryOff turns off project memory and everyday memory in every chat.

On a phone or browser page

These switches, the memory list and Keep work only in Bunny's own window. A device can read that a project has memory, and cannot change it.
