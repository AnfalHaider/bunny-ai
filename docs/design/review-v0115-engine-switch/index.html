Switch a chat's engine midway

v0.1.15 · ENGINE-SWITCH (MEDIUM) · Code chats · invented profile only · from Tech Lead's spec, 9979b4d9

For approval

In short

Today a chat's engine is fixed at its first message; the only way to use another is a new chat. Proposed: the engine chip offers Switch this chat to…. A confirm card says what the new engine gets: this chat's folder, its instruction files, a summary of the conversation and the list of files this chat changed, so it "knows what we're talking about".

  • Only between replies, only in a Code chat with a folder (Bunny's engine is always allowed). Never from a phone or other device.
  • Engines that aren't ready are shown with the reason and the button that fixes it (Download, Sign in).
  • The transcript gets a divider ("Now on Codex"). The reply that follows shows the size of the handover.
  • Switching clears "Allowed for this chat" actions (F9), and checkpoints stay per chat, so Undo and Rewind still work.

2 · The confirm card

Desktop

Bunny
Switch this chat to Codex CLI?
It carries on in C:\Users\Sam\Projects\carrot-shop.

Codex follows Bunny's rules. (When Bunny's engine is off it would follow its own rules, which you set in Settings → Engines; the card says which.)

It gets this chat's folder, its instruction files, a summary of the conversation and the list of files this chat changed.

Actions you allowed for this chat are cleared. Your files and Undo stay as they are.

The button names what it does.

Phone (360 px)

Bunny
Switch this chat to Codex CLI?

It gets this chat's folder, its instruction files, a summary of the conversation and the files this chat changed. It follows Bunny's rules.

On a phone signed in as a device the chip has no switch (see 4); this is the card on the PC window narrowed.

Variant: it runs restricted

Bunny
Switch this chat to Claude Code?

Claude Code runs restricted in this chat: Bunny's check failed for it earlier. It works in a copy of your folder, and you review the changes before they reach it.

Variant: engine's own rules

Bunny
Switch this chat to Codex CLI?

Bunny's engine is off, so Codex follows its own rules: it asks you about every command and file change.

The divider stays in the transcript. The size line is in the reply's details, so a person can see the handover happened without the handover text being saved in the chat.

Rewind knows which engine

Reply 7 (Codex CLI) · 10:58Add a sold-out label2 files

A rewind across a switch is allowed: the files belong to the folder, not the engine. The next engine is told about the rewind.
