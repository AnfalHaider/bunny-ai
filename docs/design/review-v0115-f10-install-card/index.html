One card to install and switch on

v0.1.15 · AGENT-FLOW F10 (HIGH) · plugins and connectors Bunny adds for a task · invented profile only · from Tech Lead's spec, ed2b61ae

For approval

In short

Today, when Bunny adds a plugin or connector for a task, the person answers two cards: one to install, then "Switch on what was just added?". Proposed: one card, "Install and switch on <name>?", that shows everything both cards show now, with three buttons. The task then carries on in the same reply.

  • The buttons: Install and switch on, Install, keep off, Don't install.
  • Nothing Bunny adds is ever on without the window's yes; that yes is now given on the one card that shows it all.
  • The same card in every mode, Auto included. In Auto that is the same number of cards as today for a remote connector and one fewer for a local one.
  • Over-long descriptions: no "switch on" button; it installs off, and says so.
  • Plan mode refuses; a device cannot install; "install from GitHub" keeps its own card with "switch on" added.
