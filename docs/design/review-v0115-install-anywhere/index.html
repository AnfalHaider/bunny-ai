Add from address: plugins, skills and connectors from anywhere

v0.1.15 · INSTALL-ANYWHERE (HIGH, quick sketch) · Customize · from Tech Lead's spec, 9242f04c · invented profile only

For approval

In short

Today a plugin can only come from GitHub. Proposed: in Customize, Add from address takes any of these in one field, shows what Bunny understood, and leads to the same one install card as F10, now with the exact source and pin on it. Old npx and uvx connectors that run whatever version the registry has today are marked not pinned, with Pin this version.

  • Accepted: an https address of a git host (GitHub, GitLab, Bitbucket, Codeberg or any .git), an archive (.zip, .tar, .tar.gz, .tgz), a single SKILL.md, a remote connector address, and npm:name or pypi:name packages.
  • Only https. Nothing runs at install time. Nothing is installed until the card is answered, and what is installed is exactly what the card showed.
  • Your own addresses on your own network are allowed here (the person, not the model, is adding them); the card says so plainly.
  • Only Bunny's own window can add or install; a phone cannot.
