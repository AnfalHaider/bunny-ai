In short

The Smart default starts a new Code chat in Auto (with Bunny's check on every risky action) in a git project you have trusted, and in Ask anywhere else. Trusting a folder to follow its instruction files and trusting it to start in Auto are different trusts, so one click must never grant both without saying so.

  • Drawn (recommended): one card, two separate answers. Each question has its own Yes / Not now, and nothing is chosen until the person chooses. Alternative B below names both in one button, as Security allows.
  • A folder Bunny has not seen is never trusted: a cloned or downloaded project starts in Ask until the person's click.
  • "Git project" is decided by Bunny asking git itself, not by a .git file or folder alone.
  • With the Auto check off, unreachable or failed, Smart acts as Ask. It never acts as Auto with no check.
  • Existing chats keep their mode. A phone's new chat starts in Ask whatever the default. Each trust is seen and removed on the Working folder card and in Settings → Permissions.
