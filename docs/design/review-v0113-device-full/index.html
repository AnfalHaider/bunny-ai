What is proposed, in one paragraph
Every signed-in device gets an access level, and only Bunny's window can set it. Chats is today's level and the default for a new device: chats with tools, but no computer control, installs, connectors, schedules, memory or settings. Everything is the same as Bunny's window: every tool and every setting. The level is chosen in two places, as the owner asked: when a device signs in for the first time (Bunny's window asks "What may it do?"), and later in Settings, in the signed-in devices list. A plain warning comes before Everything every time. A device with Everything sees no "Change this in Bunny's window" locks, with two exceptions: it cannot turn device access off and cannot change any device's level. Those stay with the window. The status line in the window says how many devices have Everything.

1. A device signs in for the first time

Today nothing is asked: the device signs in and is listed. In the proposal Bunny's window asks, over whatever it is showing, and the device already works at the Chats level meanwhile, so nothing waits and nothing is open by accident. If nobody answers, the level stays Chats. Choosing Everything shows the warning first, with its own button, never in one click.

2. Settings → Use Bunny in a browser → Signed-in devices

Each device shows its level beside its name, with a Change control and Sign out. Change opens two choices; picking Everything shows the same warning. Going back to Chats needs no warning and takes effect at once.

3. What a device with Everything sees

No locks: Settings, Customize, Providers and Automation all work, the same as in the window. A thin line under the top bar says which level this device has, always, so a person using it knows. Two things stay with Bunny's window: turning device access off, and changing any device's level. They show the sentence "Only Bunny's window can change device access." On a device with Chats, everything is as in the last release (locked controls with "Change this in Bunny's window.").

4. The status line in Bunny's window

The line across the top of the window already says how many devices are signed in. It now says how many of them have Everything, in the warning colour, so the most powerful state is never hidden.

Risk: HIGH, and why

Security reviews this before any build. This lifts the main protection of the other-device feature: a device at Everything can run programs, read and change files, use accounts and install tools on this computer, over plain HTTP on the local network. The owner has decided it should exist; the design keeps it deliberate, visible and reversible.
  • The level is set only from Bunny's window, with the window's own secret, never by a device and never by a request a device can make. A device cannot raise its own level, change another device's, or turn device access off.
  • The default is Chats. Everything is never the default and never set by a setting that a device can reach.
  • A plain warning before Everything, every time (the first-sign-in prompt and Settings Change). It says what Everything allows and that the connection is plain HTTP, so anyone on the network who obtains the device's session could do the same.
  • Always visible: the status line in the window counts devices with Everything; the device's own page shows its level in a line under the top bar; the devices list shows each level.
  • Sessions are the limit: device access turns off at every restart and ends every session, so every Everything grant ends with it (decision 2). Signing a device out, turning access off, or changing the passcode ends a grant at once.
  • Suggested for Security: a record of the actions an Everything device takes (a log line per tool run with the device's name), and a time limit on a grant as a later option. Neither is drawn.
  • The device-access exceptions are server rules, not just disabled buttons: a device that sends the request anyway is refused with the same sentence.

Decisions for the owner (my recommendation first)

  1. The default for a new device: Chats (recommended). A device is useful at once and gets nothing dangerous until a person at the PC says so. The other choice, Everything by default, means anyone who learns the passcode gets full control the moment they sign in.
  2. Does Everything end when Bunny restarts? It is kept per device until sign-out (recommended), which in practice means until Bunny restarts, because device access itself turns off at a restart and ends all sessions. A grant therefore never survives a restart by itself.
  3. The warning wording (draft below): the draft says what Everything allows, says the connection is plain HTTP, and says to give it only to a device you own. A shorter version ("This device will be able to do anything you can do here, including run programs on this computer.") is the alternative; I recommend the longer one for the first grant and the shorter one for each later grant on the same device.
  4. Where Everything can be chosen: both places (as asked). At first sign-in and in Settings. A device is never asked to choose its own level.
  5. An action log for Everything devices: recommended as a follow-up for Security's review, not part of this drawing.
Draft warning, for the owner's wording
"Everything means this device can do anything you can do in this window: run commands and programs on this computer, read and change your files, use your accounts and connectors, install tools and change what Bunny is allowed to do. This connection is plain HTTP on your network, so anyone on it who gets this device's session could do the same. Only give Everything to a device you own and keep locked."

Not drawn: the exact look of the dialog when several devices sign in at once (they queue, one prompt at a time), and the device's own sign-out control, which is as before.
