Sizes are the real woff2 Latin files from the font foundry's published builds, measured today. The app installer is tens of megabytes already; this adds about half a megabyte.

Things to know before this is built.
  • Latin only. The bundled files cover English and other Latin-script languages. Text in another script (Arabic, Cyrillic, Chinese and so on) shows in the system font, as it does today.
  • Italics are slanted by the browser for these fonts, not drawn. Real italics would add roughly 40 kB for each serif; not needed for the first release.
  • Phones in the browser must be allowed to load the font files. The sign-in page is the only file a device that has not signed in may get; after sign-in the font files must be served to Chats devices too, or the phone falls back to the system font.
  • The OFL licence texts must ship with the app (a Licences page under About is the usual place), and the font files must stay unmodified.
  • The existing Code font box (type any installed font) is unchanged; JetBrains Mono and IBM Plex Mono are offered here as interface and reply fonts.
