v0.1.15 · FOLDER-RULES v4 (ONE-INSTRUCTIONS, MEDIUM) · replaces the "Engine chat" state of v3 · invented profile only · from Tech Lead's spec, ed2b61ae

For approval

In short

Bunny builds one instruction text per folder and gives exactly that text to Bunny's engine, Claude Code and Codex CLI, so the three cannot disagree about the same project. Everything in v3 stays (the trust card, the 32 KB and 64 KB limits, the per-chat switch, View what was read); what changes is that engine chats are covered too.

  • Which file: AGENTS.md is the project's file. CLAUDE.md is used only when there is no AGENTS.md. If both exist, CLAUDE.md is listed as "not used". A CLAUDE.md that only says @AGENTS.md is shown as "points to AGENTS.md". Cursor's always-on rules are added after the main file.
  • Trust covers engines: before "Follow them", no engine gets the text (today Codex reads AGENTS.md unasked; this is safer).
  • Replaced state: v3 showed engine chats as "Claude Code reads it" with the switch disabled. Now they show the same block, "in use", with the same switch.
  • The files are still only the folder's words and never change permissions, for any engine.
