In short

A Code chat looks in its folder for AGENTS.md, CLAUDE.md and .cursor/rules and gives what it finds to the model as the project's instructions. The person sees it: the Working folder card lists the files in use, has one switch per chat, and a View what was read link that shows the exact text the model was given.

  • Trust first (Security FR-2): the first time a folder (by its real path) has instruction files, Bunny asks Follow them / Not now in a card in the chat, with the text readable. Nothing is followed before the person says yes. Section 1a.
  • Once followed, it is on for new chats in that folder; the switch is per chat, so one chat can ignore the files and another use them.
  • Nothing is hidden: the list is the truth, and View shows the same text the model gets.
  • The files are the project's words. They sit under the person's rules and permissions and cannot change them (wording below; Security to confirm).
  • No banner and no notice. The only other sign is the existing folder chip's tooltip ("Working folder: … · 3 instruction files").

1a · The first time: asking before following (FR-2)

Why: in Auto mode, instructions from a cloned repository could steer commands with no card. So nothing in these files is followed until the person says so, once per folder.

  • Where: a card in the chat, in the thread above the composer, the first time a Code chat starts in a folder that has instruction files and no answer is stored for it. It is the same kind of card Bunny already uses to ask for something (like switching to Code mode); one card, no banner.
  • What it knows: the folder's real path (links resolved). The answer is kept for that folder, across chats.
  • Follow them: the files are used from the next reply, in this chat and in new chats in the folder. The Working folder card then shows them "in use".
  • Not now: nothing is followed. The card closes and does not come back in this chat. A new chat in the same folder asks again. Nothing is stored as a "never".
  • Change it later: on the Working folder card (below): "Follow them…" when not followed; the switch turns them off for this chat; "Ask me again for this folder" forgets the stored answer.
