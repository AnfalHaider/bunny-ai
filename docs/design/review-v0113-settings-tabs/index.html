Settings tabs audit, v0.1.13

Every row in Settings, the tab it is in now and the tab it should be in. Read from src/ui/settings.html and the Settings tab list, at bf9f320. No pictures: this is a list of moves, not a redesign.

What I recommend

  • Fix"Use Bunny in a browser" shows in every tab. It belongs only in Desktop app. This is the bug Builder A is fixing (the install and desktop code un-hide the section after the single-tab view hid it). No row moves.
  • Move 2"Try another model when yours is busy" and "Wait for a first reply" go from Capabilities to Models. They are about which model answers, and the Models tab is where model choices live.
  • Move 2"Keep going on long jobs" and "Longest long job" go from Models to Code. Their own text says "In Code mode".
  • Move 2"Default transcript view" and "Label chats by status" go from Code to Appearance. They change how chats and the sidebar look, and Appearance already holds transcript size and width.
  • StayThe permission rules stay in Code, with Default permission mode. Rules judge the commands and file paths Bunny's tools run, which is Code-mode work, and "Try a command" tests exactly that. Privacy holds only Storage, and Capabilities holds on/off switches for features, so neither fits better. If you later want one place for everything Bunny may do, that would be a new Permissions tab, a bigger change than this audit.

Six rows move, nothing is removed, no wording changes. Everything else stays where people already look for it.
