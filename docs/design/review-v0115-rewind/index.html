Rewind: go back further than one reply

v0.1.15 · REWIND · Code chats · invented profile only (a chat of "Sam")

For approval

In short

Every reply that changed files already leaves a checkpoint. Today the person can undo one reply at a time, from the bar under that reply. Proposed: a Rewind list of every checkpoint in the chat. Pick a step, see exactly what it restores, confirm in words, and the project goes back to how it was just before that reply.

  • Two ways in: Go back further… next to the existing Undo button, and Rewind at the top of the Changes pane.
  • One row per reply that changed files, newest first. Replies that changed nothing are not listed.
  • The chat messages are never rewound; only the files.
  • Before it acts, Bunny makes a checkpoint of how things are now, so a rewind can itself be undone (Tech Lead to confirm).
