Allow for this chat, on the permission card

v0.1.15 · AGENT-FLOW F9 (HIGH) · Code chats · invented profile only (project of "Sam") · from Tech Lead's spec, ed2b61ae

For approval

In short

Today every permission card approves one call, so a 10-step job can mean 10 cards. Proposed: the card also offers Allow for this chat: <kind>, a narrow kind named in words on the button, so the same kind of action stops asking until the chat ends. An optional tick saves it as a rule for the folder.

  • Three buttons: Allow once, Allow for this chat: …, Don't allow. The kind is always spelled out ("Allow npm run commands in this chat").
  • Some cards never offer it (sending, building tools, protected paths, compound commands, your own Ask rules, a chat holding PC file text, a device). They show only Allow once and Don't allow, and say why in one line.
  • What is allowed is listed on the Working folder card, with Forget. A folder change, an engine switch or Plan mode also clears it.
  • A deny rule always wins, and an allowed kind never gets past the always-protected list.
  • Kinds are narrow (Security F9-1 to F9-3): a wide command kind exists only for a fixed list of program and sub-command pairs ("npm test commands", "git commit commands"). Interpreters, shells, downloaders, deletions and git push get only this exact command. An edit kind is one folder and below, never the whole project. Controlling the PC lasts for this task (this reply). Browser kinds are by site, and purchases, downloads and form submits are once only.

For Security and Tech Lead: (a) the one-line reasons are fixed strings, never model text; (b) the kind comes only from the call's own arguments at the moment of the card, so a hostile file cannot widen it; (c) the tick writes an Allow rule only, never removes a Deny or Ask; (d) the step mark must not be mistaken for a banner: it is a small chip on the step, nothing across the screen; (e) long paths: the folder kind shows the folder relative to the project ("src/components/"), cut in the middle if long, with the full path in the tooltip (Security answered a to e: yes).
