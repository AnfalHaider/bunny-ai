## Still open (LOW; follow-ups)
- **W27d-1:** an argument that PowerShell computes is not seen as dynamic, so these dodge a `git push*` Deny: ``git `-C . push`` (a backtick before an option), `git ("push")`, `git @("push")`, `git $("push")`. The variable form `git $a` is caught; the parenthesised, array and subexpression forms are not. Fix: when a Deny or Ask rule exists for a command, treat a call to it whose argument contains `(`, `@(`, `$(` or a backtick before a hyphen as Ask, as the wrappers are. Builder's Settings note ("a guard rail, not a sandbox") already tells the person this class exists.
