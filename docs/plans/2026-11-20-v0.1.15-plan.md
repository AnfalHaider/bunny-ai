## HIGH item answers (typed in the Chief of Staff's chat, 2026-11-20)

- **F9 "Allow for this chat":**
  - I asked: "Should Bunny add "Allow for this chat" for these narrow kinds of action, or not yet?" The narrow kinds are a command starting with a given word, edits inside one folder, one exact connector tool, computer use, and browser actions on one site. It's never offered for chained or redirected commands, sending, building tools, ask-rule cards, after a PC file read, or on a device, and Deny always wins.
  - Owner: "Yes, add it".
  - Built after Design's drawing, with Security's review (spec ed2b61ae).
- **F10 one install card:**
  - I asked: "Should Bunny use one install card with these three choices, or keep the two cards?" The three choices are Install and switch on, Install and keep off, and Don't install. The card shows everything the two cards show today, works only in the window, and the tools work in the same reply.
  - Owner: "Yes, one card".
  - Built after Design's drawing, with Security's review.
- **F11 Auto with a safety judge:**
  - I asked: "Should Bunny add Auto with a safety judge under these conditions, or not yet?" The conditions are Security's F11-1 to F11-7:
    - the judge sees only the typed turns and the call, never files or instruction files;
    - anything unclear, cut off or unanswered is a block;
    - a fall-back means cards, never run;
    - sending and building tools always ask;
    - it uses the same provider unless one is chosen in Settings;
    - every verdict is shown.
  - Owner: "Yes, add the judge".
  - Built after Design's drawing (https://claude.ai/artifact/JtLH5EMEhaTcDBet9GW1gr), with Security's review.
- **F13 command confinement:**
  - I asked: "Should Bunny add command confinement so commands can only write inside the project folder, or not yet?" The approach:
    - Codex's own Windows sandbox when Codex is installed, otherwise a low-integrity helper;
    - reads and the network are not stopped, and the help says so;
    - never a drive root, home, Desktop, Documents or Downloads;
    - removable per folder;
    - a card instead of ever running unconfined;
    - an optional work-in-a-copy mode for untrusted projects.
  - Owner: "Yes, add it".
  - Spike S-F13B comes first; Security's F13-1 to F13-5 apply.
- **F12 Smart default:**
  - I asked: "Should "Smart" be the default (Auto in trusted project folders, Ask everywhere else), or should new chats keep starting in Ask?" Under Smart:
    - Auto with the safety judge only in folders marked trusted that are real git projects;
    - Ask for unseen folders, devices, and when the judge is unavailable;
    - existing choices kept;
    - trusting a folder's instructions and trusting it for Auto are separate, or one card names both.
  - Owner: "Yes, Smart default".
  - Not built without F11; Security's F12-1 to F12-4 apply.
- **F8 and the Search this PC default:**
  - I asked: "Should Search this PC be on by default for finding files only, with the one-click card? Or keep it off, with just the one-click card to turn it on?" The conditions are Security's:
    - finding only, with reading staying the person's choice;
    - a one-time notice that names and folders go to the model and provider;
    - on only where pcSearchEnabled was never written;
    - the fixed exclusions unchanged;
    - never a Chats device.
  - Owner: "Yes, finding only".
  - Security's conditions (1 to 7) and F8-1 to F8-3 apply.
- **PG-4 protected files that always ask:**
  - I asked: "Should Bunny add protected files that always ask, even in Auto, flagged on engine cards too, or not yet?"
  - Owner: "Not yet".
  - PG-4 is out of v0.1.15. Note for Security and Tech Lead: without PG-4, Bunny's own file tools can edit AGENTS.md, CLAUDE.md and .cursor/rules in Auto, so FOLDER-RULES must handle that some other way. Today's RUNS_LATER protection is unchanged.
